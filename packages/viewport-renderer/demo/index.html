uCode - Runtime and GridCore Display

Tabs: terminal (OK prompt) | teletext (CEEFAX reader) | pixel (24x24 pixel editor) | grid (character editor) | layer (layer stack)
Terminal: type HELP, CEEFAX (switches to Teletext), GRID SET 10 10 X, WORLD LIST.
Teletext: number keys 0-9 navigate pages, ESC or B go back.
