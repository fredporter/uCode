# Changelog

uCode is pre-release. No public version has been issued.

## Unreleased

### Current baseline

- GridCore, viewport renderer, GridSmith, BASIC, and AMOS packages share one
  repository and verification workflow.
- Internal BASIC command control is named Runtime Control Protocol (RCP).
- External Model Context Protocol is owned by uCore's `udos-mcp` gateway.
- Unsupported socket gateways, duplicated agent APIs, generated CLI fragments,
  compatibility shims, and copied backup subsystems have been removed.

Historical release claims made before pre-release convergence are not releases
and are intentionally not retained as version entries.
